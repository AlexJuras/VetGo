# VetGo - Sistema de Gestão para Clínicas Veterinárias Universitárias

## 📋 Sobre o Projeto

VetGo é um sistema web desenvolvido para gerenciar clínicas veterinárias universitárias, facilitando o controle de consultas, cadastro de animais, tutores e estudantes de veterinária. O sistema oferece uma interface moderna e intuitiva, desenvolvida com Laravel e Vue.js.

## 🚀 Principais Funcionalidades

### 🐾 Gestão de Animais
- Cadastro completo do animal com informações detalhadas
- Histórico médico
- Status do animal (Internado, Em Atendimento, Alta)
- Vínculo com tutor responsável
- Registro de consultas e tratamentos

### 👥 Gestão de Tutores
- Cadastro de tutores com dados pessoais
- Visualização dos animais vinculados
- Histórico de consultas
- Gerenciamento de contatos

### 👨‍⚕️ Gestão de Estudantes/Veterinários
- Registro de estudantes/veterinários
- Controle de atendimentos realizados
- Histórico de consultas atendidas
- Gerenciamento de agenda

### 📅 Gerenciamento de Consultas
- Agendamento de consultas
- Status automático baseado no horário:
  - Agendada
  - Em Andamento (durante horário marcado)
  - Concluída (após horário)
  - Cancelada (manualmente)
- Registro de procedimentos
- Histórico completo

### 📊 Dashboard
- Total de animais cadastrados
- Número de consultas do dia
- Próximas consultas (2 horas seguintes)
- Novos cadastros da semana
- Receita mensal
- Estatísticas gerais
